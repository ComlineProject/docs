# Tools

| Tool | What it's for |
| --- | --- |
| [`comline`](cli/index.md) | The CLI: scaffold, check, build, release, diff, generation, document. |
| [`comline inspect`](cli/inspect.md) | What each protocol resolves to on the wire, and the guarantees it keeps or gives up. |
| [`comline doc`](cli/doc.md) | Documentation pages, a static site or a JSON model, for every version. |
| The language server | Diagnostics, hover, completion, go-to-definition and quick fixes in `.ids`, `config.idp` and `comline.toml`, through any LSP editor. |
| The [playground](https://github.com/ComlineProject/playground) | Compile, generate and simulate calls in the browser. |
